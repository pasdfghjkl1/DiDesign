## 📝 Как добавить новый проект

1. Откройте `data/portfolio.json`
2. Скопируйте блок любого проекта
3. Измените данные под ваш проект:
   - `id` - уникальный идентификатор
   - `title` - название проекта
   - `description` - краткое описание
   - `mainImage` и `gallery` - пути к изображениям
4. Загрузите изображения в `images/portfolio/[id-проекта]/`
5. Сохраните изменения

Подробная инструкция: [PORTFOLIO_GUIDE.md](PORTFOLIO_GUIDE.md)
