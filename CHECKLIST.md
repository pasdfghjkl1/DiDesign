## 🚨 Возможные проблемы и решения

### Проблема 1: "Access Key не настроен"
**Причина**: Вы не заменили `YOUR_ACCESS_KEY_HERE`  
**Решение**: Следуйте инструкции в `FORM_SETUP.md`

### Проблема 2: Письма не приходят
**Причина**: Email не подтверждён или в спаме  
**Решение**: 
- Проверьте папку "Спам"
- Подтвердите email на Web3Forms
- Проверьте правильность Access Key

### Проблема 3: Слайдеры не работают
**Причина**: Swiper не загрузился  
**Решение**: 
- Очистите кэш браузера (Ctrl+Shift+Del)
- Обновите страницу с Ctrl+F5
- Проверьте консоль браузера (F12)

### Проблема 4: Баннеры не зелёные
**Причина**: Кэш браузера или CSS не загрузился  
**Решение**:
- Обновите страницу с Ctrl+F5
- Подождите 1-2 минуты обновления GitHub Pages

## 🐛 Решение проблем

### Проблема: Форма не открывается
**Решение:**
1. Открыть консоль (F12)
2. Посмотреть ошибки
3. Проверить что файлы `js/contact-form.js` и `css/contact-form.css` подключены

### Проблема: Заявки не сохраняются
**Решение:**
1. Проверить в консоли: `DIForms.exportLeads()`
2. Если пусто - проверить что форма отправляется
3. Проверить что localStorage не заблокирован в браузере

### Проблема: Python скрипт выдает ошибку
**Решение:**
1. Закрыть Excel файл
2. Проверить что файл существует
3. Проверить права доступа к файлу
4. Переустановить openpyxl: `pip install --upgrade openpyxl`

### Проблема: Кириллица не отображается в консоли
**Решение:**
- Это нормально для Windows PowerShell
- Данные в Excel сохраняются корректно
- Игнорируйте это
