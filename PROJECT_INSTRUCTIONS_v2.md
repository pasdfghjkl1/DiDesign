## ⚠️ КРИТИЧЕСКИ ВАЖНО

### 🚨 Работа с файлами - ОСНОВНЫЕ ПРАВИЛА

1. **НИКОГДА не используй режим `append` при записи `portfolio.json`**
   - ❌ `mode: "append"` приводит к дублированию данных и порче файла
   - ✅ Всегда используй `mode: "rewrite"` при первой записи
   - ✅ Для добавления контента используй только последовательную запись с `rewrite` один раз

2. **Всегда используй абсолютные пути**
   - ✅ `C:\Users\pa8hka\Desktop\site\data\portfolio.json`
   - ❌ НЕ используй относительные пути

3. **Проверка файла после изменений**
   - После любых изменений в `portfolio.json` проверь его валидность
   - Команда проверки: `python -m json.tool data/portfolio.json`

## 📋 Чек-лист при изменениях

### Перед изменениями:
- [ ] Сделай backup файла (если меняешь `portfolio.json`)
- [ ] Проверь текущее состояние через `git status`

### После изменений:
- [ ] Проверь валидность изменений (визуально или через инструменты)
- [ ] Проверь адаптивность (если менял стили)
- [ ] Добавь файлы в Git: `git add`
- [ ] Создай коммит с понятным описанием: `git commit -m "..."`
- [ ] Отправь на GitHub: `git push origin main`
- [ ] Подожди 2-5 минут для обновления GitHub Pages
- [ ] Проверь сайт с жёсткой перезагрузкой: **Ctrl+F5**

## 🚨 Распространённые проблемы

### Проблема 1: "Ошибка загрузки проектов"
**Причина**: Повреждён `portfolio.json`  
**Решение**: Восстановить из Git или backup

### Проблема 2: Изменения не видны на сайте
**Причина**: Кэш браузера или GitHub Pages не обновился  
**Решение**: 
- Нажми **Ctrl+F5** для жёсткого обновления
- Подожди 5-10 минут для обновления GitHub Pages

### Проблема 3: Git команды не работают
**Причина**: Неправильный синтаксис для PowerShell  
**Решение**: Используй синтаксис с `&` и одинарными кавычками (см. примеры выше)
