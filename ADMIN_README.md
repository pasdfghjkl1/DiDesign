# 🛡️ Админ-панель DI Studio

## 📋 Описание

Админ-панель для управления клиентами и их проектами. Предоставляет полный контроль над базой данных клиентов через удобный веб-интерфейс.

---

## 🚀 Функционал

### ✅ Основные возможности:

1. **Просмотр списка клиентов**
   - Таблица со всеми клиентами
   - Информация о проектах
   - Статусы и прогресс

2. **Поиск клиентов**
   - По имени
   - По номеру телефона
   - По названию проекта

3. **Добавление нового клиента**
   - Личная информация
   - Данные проекта
   - Автоматическое создание документа в Firestore

4. **Редактирование клиента**
   - Обновление всех полей
   - Изменение статуса проекта
   - Обновление прогресса

5. **Удаление клиента**
   - С подтверждением
   - Безопасное удаление из базы

6. **Статистика**
   - Общее количество клиентов
   - Активные проекты
   - Завершённые проекты

---

## 🔐 Вход в админ-панель

### Создание администратора в Firebase:

1. Открой Firebase Console → Firestore Database
2. Создай документ в коллекции `clients`
3. **Document ID:** номер телефона администратора (например: `79991234567`)
4. **Поля документа:**

```javascript
{
  personalInfo: {
    name: "Администратор",
    phone: "+7 (999) 123-45-67",
    email: "admin@di-studio.local"
  },
  isAdmin: true,              // ВАЖНО: это делает пользователя администратором
  hasPassword: false,          // При первом входе нужно создать пароль
  createdAt: [текущая дата]
}
```

5. Сохрани документ
6. Перейди на страницу входа: `/client-login.html`
7. Введи номер телефона администратора
8. Создай пароль
9. Автоматически откроется админ-панель

## 📊 Правила Firestore для админа

```javascript
match /clients/{clientId} {
  // Админы видят всех клиентов
  allow read: if request.auth != null && 
                 get(/databases/$(database)/documents/clients/$(request.auth.token.email.split('@')[0])).data.isAdmin == true;
  
  // Админы могут создавать и изменять клиентов
  allow write: if request.auth != null && 
                  get(/databases/$(database)/documents/clients/$(request.auth.token.email.split('@')[0])).data.isAdmin == true;
}
```

## 🚨 Важные замечания

### ⚠️ Первый запуск:

1. **Создай администратора в Firestore** - это обязательно!
2. **Установи `isAdmin: true`** - без этого админ-панель не откроется
3. **Настрой правила Firestore** - для доступа к данным

### ⚠️ Безопасность:

- Не используй простые пароли для администратора
- Храни данные администратора в секрете
- Регулярно проверяй логи доступа

### ⚠️ Производительность:

- При большом количестве клиентов (>100) рассмотри пагинацию
- Добавь индексы в Firestore для быстрого поиска
