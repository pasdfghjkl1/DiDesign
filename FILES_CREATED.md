### Шаг 1: Интеграция на сайт
Следуйте инструкциям из `INTEGRATION_GUIDE.html`

### Шаг 2: Тестирование
```bash
# Добавьте тестовую заявку
python stats/add_lead.py --name "Тест" --phone "+7..." --email "test@test.com"

# Добавьте тестовую аналитику
python stats/add_analytics.py --date "12.10.2025" --visitors 10 --views 50 --avgtime 3
```
