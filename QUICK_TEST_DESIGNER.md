## 🐛 Если что-то не работает

### Проблема: "Нет назначенных проектов"

**Проверьте:**
```javascript
// У работника:
role = "designer"
assignedProjects = ["79823076609", "79991234567"]

// У клиентов:
assignedDesigner = "79217653621"
```

### Проблема: Редирект на другую страницу

**Проверьте:**
```javascript
role = "designer"  // НЕ "admin", НЕ "client"
isAdmin = false
```

### Проблема: Чат не загружается

1. Откройте консоль браузера (F12)
2. Ищите ошибки
3. Если "Missing index" → Firebase предложит создать индекс, нажмите на ссылку

### Проблема: Не отправляются сообщения

**Проверьте правила Firestore:**
1. Firebase Console → Firestore → Rules
2. Должно быть: `allow read, write: if true;` (для тестирования)
