## 📈 ПРОЦЕСС СБОРА АНАЛИТИКИ

```
ПОЛЬЗОВАТЕЛЬ ЗАХОДИТ НА САЙТ
         │
         │ 1. Загружается analytics.js
         ▼
    ┌──────────┐
    │ Создается│
    │ сессия   │
    │ ID       │
    └────┬─────┘
         │
         │ 2. Начинается отслеживание:
         ▼
    ┌──────────────────────────┐
    │  • Время начала сессии   │
    │  • Текущая страница      │
    │  • Источник (referrer)   │
    └────┬─────────────────────┘
         │
         │ 3. Пользователь перемещается по сайту
         ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ Главная  │───▶│Портфолио │───▶│ Услуги  │
    │ 45 сек   │    │ 2 мин    │    │ 1 мин   │
    └──────────┘    └──────────┘    └──────────┘
         │                │                │
         └────────────────┴────────────────┘
                          │
         │ 4. Каждые 30 сек или при закрытии
         ▼
    ┌──────────┐
    │ Отправка │
    │ данных   │
    └────┬─────┘
         │
         │ 5. Сохранение в localStorage
         ▼
    ┌──────────┐
    │{         │
    │ session: │
    │ time:    │
    │ pages: [ │
    │   {...}  │
    │ ]        │
    │}         │
    └────┬─────┘
         │
         │ 6. В конце дня менеджер агрегирует
         ▼
    ┌──────────┐
    │ Python   │
    │ add_     │
    │analytics │
    └────┬─────┘
         │
         ▼
    ┌──────────┐
    │ Статис-  │
    │ тика в   │
    │ Excel    │
    └──────────┘
```

## 🎯 КЛЮЧЕВЫЕ ТОЧКИ

### ✅ Автоматически:
- Создание сессии при заходе
- Отслеживание времени на странице
- Сохранение данных формы в localStorage
- Периодическая отправка аналитики

### ⏳ Требует действий менеджера:
- Перенос заявок в Excel (через add_lead.py)
- Агрегация аналитики за день (через add_analytics.py)
- Обработка заявок (изменение статуса)
- Анализ статистики

### 🚀 Можно автоматизировать (будущее):
- Backend сервер для автосохранения
- Email уведомления о заявках
- Автоматическая агрегация аналитики
- Dashboard для визуализации
