## 💡 Советы по использованию

### Для администратора:

1. **Создание клиента**
   - Всегда используйте номер телефона без пробелов как ID
   - Обязательно `hasPassword: false` для новых клиентов
   - Заполните project.title - клиент сразу увидит название

2. **Загрузка файлов**
   - Называйте файлы понятно: "Гостиная_v2.jpg"
   - Указывайте версию в поле version
   - Добавляйте заметки о изменениях

3. **Организация**
   - Группируйте файлы по помещениям (room)
   - Используйте type корректно (render/drawing/document)
   - Обновляйте прогресс проекта регулярно

### Для клиентов:

1. **Первый вход**
   - Используйте надёжный пароль (минимум 6 символов)
   - Запомните или запишите пароль
   - Проверьте все разделы кабинета

2. **Работа с файлами**
   - Скачивайте файлы для просмотра без интернета
   - Проверяйте версии перед скачиванием
   - Читайте заметки к файлам

3. **Оплата счетов**
   - Проверяйте раздел "Счета" регулярно
   - Скачивайте счета для бухгалтерии
   - Сообщайте об оплате дизайнеру

## 📞 FAQ - Частые вопросы

### Для клиентов:

**Q: Забыл пароль, что делать?**
A: Свяжитесь с вашим дизайнером, он сбросит пароль.

**Q: Не вижу новые файлы**
A: Обновите страницу (Ctrl+F5) или очистите кеш.

**Q: Файл не открывается**
A: Проверьте интернет-соединение и попробуйте скачать файл.

**Q: Как оплатить счёт?**
A: Скачайте счёт из раздела "Счета и документы" и оплатите удобным способом.

### Для администратора:

**Q: Как изменить номер телефона клиента?**
A: Создайте нового клиента с новым номером, скопируйте данные.

**Q: Можно ли удалить файл?**
A: Да, удалите документ из Firestore и файл из Storage.

**Q: Как обновить прогресс проекта?**
A: В Firestore откройте clients/{phone}/project/progress и измените число.

**Q: Превышен лимит Firebase, что делать?**
A: Перейдите на платный тарифBlaze или оптимизируйте запросы.
