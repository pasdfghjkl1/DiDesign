# 👷 Кабинет работника (Designer Dashboard) - DI Studio

## 📋 Описание

Кабинет работника предназначен для дизайнеров/менеджеров проектов, которые ведут проекты клиентов. Работник может управлять своими проектами, общаться с клиентами через чат, загружать файлы и устанавливать этапы (milestones).

---

## 🚀 Основной функционал

### ✅ Реализовано:

1. **Авторизация по ролям**
   - Автоматическое определение роли при входе
   - Редирект на правильную страницу (admin/designer/client)
   - Защита от неавторизованного доступа

2. **Мои проекты**
   - Отображение всех назначенных проектов
   - Карточки с информацией о проекте
   - Прогресс-бар выполнения
   - Индикация срочности (красная полоса для дедлайнов < 7 дней)
   - Быстрый переход в чат с клиентом

3. **Система чата**
   - Real-time обновление сообщений (Firebase onSnapshot)
   - Список всех чатов с клиентами
   - Индикация непрочитанных сообщений
   - Отправка/получение сообщений
   - Автоматическая отметка прочитанных
   - Badge с количеством новых сообщений

### 🔜 Запланировано:

- **Загрузка файлов** (требуется настройка Firebase Storage)
- **Управление этапами** (создание, редактирование, удаление milestones)
- **Версионность файлов**
- **Уведомления клиентам**
- **Детальная информация о проекте**

## 🎯 Как работает система ролей

### Поля в Firestore (коллекция `clients`):

```javascript
{
  // Личная информация
  personalInfo: {
    name: "Имя работника",
    phone: "+7 (921) 765-36-21",
    email: "designer@di-studio.com"
  },
  
  // НОВОЕ: Роль пользователя
  role: "designer",  // "admin" | "designer" | "client"
  
  // Флаги авторизации
  hasPassword: true,
  isAdmin: false,
  
  // ДЛЯ РАБОТНИКОВ: Назначенные проекты
  assignedProjects: ["79823076609", "79991234567"],  // ID клиентов
  
  // ДЛЯ КЛИЕНТОВ: Назначенный работник
  assignedDesigner: "79217653621",  // ID работника
  
  // Информация о проекте (если это клиент)
  projectInfo: {
    title: "Дизайн квартиры 70м²",
    area: "70 м²",
    status: "В работе",
    progress: 45,
    startDate: "2025-10-01",
    deadline: "2025-11-30"
  },
  
  // Чат (для обеих сторон)
  chat: {
    lastMessageText: "Готов первый рендер",
    lastMessageAt: timestamp,
    unreadByClient: 2,      // Непрочитанных клиентом
    unreadByDesigner: 0     // Непрочитанных работником
  },
  
  createdAt: timestamp
}
```

## 🔐 Создание тестового работника

### Вариант 1: Преобразовать существующего пользователя

Если у тебя уже есть пользователь (например, администратор), можешь сделать его работником:

1. Открой Firebase Console → Firestore
2. Найди документ пользователя (например, `79217653621`)
3. Добавь/измени поля:

```javascript
{
  role: "designer",           // Устанавливаем роль
  isAdmin: false,             // Убираем права администратора
  assignedProjects: [         // Назначаем проекты
    "79823076609",            // ID первого клиента
    "79991234567"             // ID второго клиента
  ]
}
```

4. Сохрани изменения

### Вариант 2: Создать нового работника (через админку - БУДЕТ РЕАЛИЗОВАНО)

В будущем администратор сможет создавать работников прямо из админ-панели.

## 🧪 Как протестировать

### Шаг 1: Создай/обнови работника в Firestore

```javascript
// Document ID: 79217653621 (или любой другой номер)
{
  personalInfo: {
    name: "Павел Иванов",
    phone: "+7 (921) 765-36-21",
    email: "designer@di-studio.com"
  },
  role: "designer",
  hasPassword: false,  // Если пароль не создан
  isAdmin: false,
  assignedProjects: ["79823076609", "79991234567"],
  createdAt: [текущая дата]
}
```

### Шаг 2: Назначь работника на проекты клиентов

Для каждого клиента в `assignedProjects` добавь поле:

```javascript
// Document: 79823076609 (клиент 1)
{
  assignedDesigner: "79217653621",  // ID работника
  // ... остальные поля клиента
}

// Document: 79991234567 (клиент 2)
{
  assignedDesigner: "79217653621",  // ID работника
  // ... остальные поля клиента
}
```

### Шаг 3: Создай коллекцию `messages` (если её нет)

Firebase создаст коллекцию автоматически при первом сообщении.

**ИЛИ** создай вручную:
1. Firestore Console → Начать коллекцию
2. Имя: `messages`
3. Добавь первое тестовое сообщение

### Шаг 4: Войди как работник

1. Открой `/client-login.html`
2. Введи номер работника: `+7 (921) 765-36-21`
3. Если пароля нет - создай его
4. Если пароль есть - введи
5. Автоматически откроется `designer-dashboard.html`

### Шаг 5: Проверь функции

- ✅ Видны назначенные проекты
- ✅ Есть badge с количеством проектов
- ✅ Можно открыть чат с клиентом
- ✅ Можно отправить сообщение
- ✅ Сообщения обновляются в реальном времени

## 🎨 Интерфейс

### Табы (вкладки):

1. **Мои проекты** - список назначенных проектов с карточками
2. **Чат с клиентами** - переписка по проектам
3. **Загрузка файлов** - раздел в разработке
4. **Управление этапами** - раздел в разработке

### Карточка проекта:

- Название проекта
- Имя клиента
- Статус (В работе / Завершён)
- Площадь
- Дедлайн
- Прогресс-бар (%)
- Кнопки: "Открыть чат" / "Детали"

### Чат:

**Sidebar (левая панель):**
- Список всех проектов
- Имя клиента
- Последнее сообщение
- Время
- Индикатор непрочитанных (зелёная полоса)

**Основная область:**
- Заголовок с именем клиента
- Сообщения (прокрутка)
- Поле ввода + кнопка отправки

## 🔄 Real-time обновления

### Чат работает в реальном времени:

```javascript
// Используется Firebase onSnapshot
firebaseDb.collection('messages')
  .where('projectId', '==', projectId)
  .orderBy('timestamp', 'asc')
  .onSnapshot(snapshot => {
    // Автоматически обновляет интерфейс при новых сообщениях
  });
```

**Это означает:**
- Новые сообщения появляются сразу (без обновления страницы)
- Если клиент пишет - работник видит мгновенно
- Если работник пишет - клиент видит мгновенно

## 📊 Структура сообщений в Firestore

### Коллекция: `messages`

```javascript
{
  messageId: "auto-generated",
  projectId: "79991234567",        // ID клиента = ID проекта
  senderId: "79217653621",         // Телефон отправителя
  senderRole: "designer",          // "designer" | "client"
  senderName: "Павел Иванов",
  text: "Готов первый рендер",
  timestamp: timestamp,
  isRead: false                    // Прочитано ли сообщение
}
```

### Индексы в Firestore (ВАЖНО!)

Для работы чата нужны индексы:

1. Открой Firebase Console → Firestore → Indexes
2. Создай составной индекс:
   - Коллекция: `messages`
   - Поля: `projectId` (ASC) → `timestamp` (ASC)
   - Статус запроса: включён

**ИЛИ** Firebase предложит создать индекс автоматически при первом запросе.

## 🚨 Важные замечания

### ⚠️ Безопасность:

**Обновите правила Firestore:**

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Правило для клиентов
    match /clients/{clientId} {
      // Чтение: клиент видит только свои данные
      allow read: if request.auth != null && 
                     (request.auth.token.email.split('@')[0] == clientId ||
                      // Работник видит назначенные проекты
                      get(/databases/$(database)/documents/clients/$(request.auth.token.email.split('@')[0])).data.assignedProjects.hasAny([clientId]) ||
                      // Админ видит всё
                      get(/databases/$(database)/documents/clients/$(request.auth.token.email.split('@')[0])).data.isAdmin == true);
      
      // Запись: только администраторы
      allow write: if request.auth != null && 
                      get(/databases/$(database)/documents/clients/$(request.auth.token.email.split('@')[0])).data.isAdmin == true;
    }
    
    // Правило для сообщений
    match /messages/{messageId} {
      // Чтение: только участники проекта
      allow read: if request.auth != null && 
                     (request.auth.token.email.split('@')[0] == resource.data.projectId ||
                      get(/databases/$(database)/documents/clients/$(request.auth.token.email.split('@')[0])).data.assignedProjects.hasAny([resource.data.projectId]));
      
      // Запись: только авторизованные
      allow create: if request.auth != null &&
                       (request.auth.token.email.split('@')[0] == request.resource.data.projectId ||
                        get(/databases/$(database)/documents/clients/$(request.auth.token.email.split('@')[0])).data.assignedProjects.hasAny([request.resource.data.projectId]));
    }
  }
}
```

### ⚠️ Firebase Storage (для будущих файлов):

1. Включи Firebase Storage в консоли
2. Настрой правила доступа
3. Обнови код для загрузки файлов

## 🐛 Возможные проблемы

### Проблема 1: "Нет назначенных проектов"

**Причина:** Поле `assignedProjects` не заполнено или заполнено неправильно

**Решение:**
1. Проверь что `assignedProjects` - массив с ID клиентов
2. Проверь что ID клиентов существуют в базе
3. Проверь что у клиентов есть поле `assignedDesigner` с ID работника

### Проблема 2: Чат не работает

**Причина:** Нет индекса в Firestore или проблемы с правилами

**Решение:**
1. Проверь консоль браузера на ошибки
2. Создай индекс (см. выше)
3. Проверь правила Firestore

### Проблема 3: Редирект на другую страницу

**Причина:** Роль пользователя настроена неправильно

**Решение:**
1. Проверь поле `role` в Firestore (должно быть "designer")
2. Проверь что `isAdmin` = false
3. Очисти кэш браузера и перезайди
