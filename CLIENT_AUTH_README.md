## 🚀 Что нужно сделать

### 1. Настроить Firebase (15 минут)

1. Создайте проект на https://console.firebase.google.com/
2. Включите **Authentication** (Email/Password)
3. Создайте **Firestore Database**
4. Создайте **Cloud Storage**
5. Скопируйте конфигурацию в `js/firebase-config.js`

**Подробная инструкция**: см. файл `SETUP_INSTRUCTIONS.md`

### 2. Добавить тестового клиента

Через консоль Firebase Firestore:
- Collection: `clients`
- Document ID: `79991234567` (номер телефона без спецсимволов)
- Поля: `personalInfo`, `hasPassword: false`, `project`

**Подробная структура данных**: см. `SETUP_INSTRUCTIONS.md`

### 3. Протестировать локально

```bash
# Откройте index.html в браузере
# Нажмите "Войти"
# Введите: +7 (999) 123-45-67
# Создайте пароль
# Проверьте все разделы личного кабинета
```

### 4. Задеплоить на GitHub Pages

```bash
cd /d C:\Users\pa8hka\Desktop\site

git commit -m "Добавлена система авторизации клиентов"
```

## 📊 Структура базы данных

```
Firestore:
clients/
  {phone}/                    ← Номер телефона без спецсимволов
    personalInfo: {...}       ← Имя, email, телефон
    hasPassword: false        ← Меняется на true после создания пароля
    project: {...}            ← Инфо о проекте, прогресс, этапы
    specifications: {...}     ← Материалы, освещение, мебель
    
    files/                    ← Подколлекция
      {fileId}/
        name, type, room, version, url, uploadDate, notes
    
    documents/                ← Подколлекция
      {docId}/
        type, number, date, amount, status, url
```
