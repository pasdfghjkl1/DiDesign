### 2. **Python скрипты** ✅

#### `add_lead.py`
Добавляет заявки в Excel файл

**Использование:**
```bash
python stats/add_lead.py \
    --name "Имя" \
    --phone "+7..." \
    --email "email@example.com" \
    --type "Тип заявки" \
    --message "Текст" \
    --page "page.html"
```

#### `add_analytics.py`
Добавляет аналитику за день

**Использование:**
```bash
python stats/add_analytics.py \
    --date "12.10.2025" \
    --visitors 25 \
    --views 120 \
    --avgtime 4.5 \
    --home 25 --portfolio 40 --services 30
```

#### `view_data.py`
Просмотр данных из Excel

**Использование:**
```bash
python stats/view_data.py --leads --limit 10
python stats/view_data.py --analytics --limit 7
```

#### `update_stats.py`
Обновляет структуру Excel файла (служебный)

## 🚀 Как использовать

### Вариант 1: Полная автоматизация (с backend)

1. Разверните Flask/Node.js сервер
2. Подключите скрипты к API endpoints
3. Форма будет автоматически сохранять заявки в Excel

### Вариант 2: Полуавтоматический (текущий)

1. Интегрируйте форму и аналитику на сайт
2. Данные сохраняются в localStorage браузера
3. Периодически переносите данные в Excel вручную через скрипты

### Вариант 3: Ручной

1. Используйте только Excel файл
2. Вносите данные через Python скрипты
3. Просматривайте через `view_data.py`
