## 📋 Листы в Excel файле

### 1. **Заявки с сайта**
Хранит все заявки от клиентов:
- № — порядковый номер заявки
- Дата — дата получения
- Время — время получения
- Имя — имя клиента
- Телефон — контактный телефон
- Email — электронная почта
- Тип заявки — категория (консультация, дизайн квартиры и т.д.)
- Сообщение — текст обращения
- Страница — откуда пришла заявка
- Статус — Новая/В работе/Закрыта
- Комментарий — примечания менеджера

### 2. **Аналитика сайта**
Статистика посещений по дням:
- Дата
- Уникальных посетителей
- Всего просмотров
- Среднее время на сайте (мин)
- Главная страница (просмотров)
- Портфолио (просмотров)
- Услуги (просмотров)
- Чертежи (просмотров)
- О нас (просмотров)
- Отказы (%)
- Источник трафика

## 🚀 Использование

### Добавление заявки вручную

```bash
python stats/add_lead.py \
    --name "Иван Петров" \
    --phone "+7 999 123-45-67" \
    --email "ivan@example.com" \
    --type "Дизайн квартиры" \
    --message "Хочу узнать стоимость дизайна 2-комнатной квартиры" \
    --page "portfolio.html" \
    --status "Новая"
```

### Добавление аналитики за день

```bash
python stats/add_analytics.py \
    --date "12.10.2025" \
    --visitors 25 \
    --views 120 \
    --avgtime 4.5 \
    --home 25 \
    --portfolio 40 \
    --services 30 \
    --drawings 15 \
    --about 10 \
    --bounce 15 \
    --source "Google"
```

## 🌐 Интеграция с сайтом

### 1. Подключение аналитики

Добавьте в `<head>` всех страниц:

```html
<script src="js/analytics.js"></script>
```

Аналитика будет автоматически отслеживать:
- Время на каждой странице
- Переходы между страницами
- Общее время на сайте
- Источник трафика

### 2. Подключение формы обратной связи

Добавьте в `<head>`:

```html
<link rel="stylesheet" href="css/contact-form.css">
<script src="js/contact-form.js"></script>
```

Вставьте форму перед закрывающим `</body>`:

```html
<!-- Включаем файл contact-form.html -->
```

### 3. Кнопка "Оставить заявку"

Добавьте на любую страницу:

```html
<button onclick="openContactForm()">Оставить заявку</button>
```

## 🔧 Автоматизация

### Вариант 1: Локальное хранение (текущее решение)

Заявки сохраняются в `localStorage` браузера. 
Для переноса в Excel используйте скрипты вручную.


### Вариант 2: Backend сервер (рекомендуется для продакшена)

Для автоматического сохранения заявок нужен простой сервер:

**Пример на Python (Flask):**

```python
from flask import Flask, request, jsonify
import subprocess

app = Flask(__name__)

@app.route('/api/submit-lead', methods=['POST'])
def submit_lead():
    data = request.json
    
    # Вызываем Python скрипт
    cmd = [
        'python', 'stats/add_lead.py',
        '--name', data['name'],
        '--phone', data['phone'],
        '--email', data.get('email', ''),
        '--type', data.get('leadType', 'Форма на сайте'),
        '--message', data.get('message', ''),
        '--page', data.get('page', ''),
    ]
    
    subprocess.run(cmd)
    return jsonify({'success': True})

if __name__ == '__main__':
    app.run(port=5000)
```

## 📈 Сбор аналитики

### Автоматический сбор

JavaScript (`analytics.js`) автоматически:
- Отслеживает сессии пользователей
- Считает время на каждой странице
- Сохраняет данные в localStorage
- Отправляет данные при закрытии вкладки

### Ручной анализ данных

1. Откройте консоль браузера
2. Проверьте localStorage:
```javascript
localStorage.getItem('di_analytics_sess_...')
```

3. Агрегируйте данные за день
4. Добавьте в Excel через `add_analytics.py`

## 🐛 Решение проблем

### Заявки не сохраняются

1. Проверьте консоль браузера (F12)
2. Убедитесь что JavaScript загружен
3. Проверьте localStorage: `localStorage.getItem('di_leads')`

### Excel файл не обновляется

1. Проверьте путь к файлу
2. Убедитесь что файл не открыт в Excel
3. Проверьте права доступа к файлу

### Кодировка в консоли Windows

Это нормально для кириллицы в PowerShell.
Данные в Excel сохраняются корректно.
