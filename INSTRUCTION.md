## 🚨 КРИТИЧЕСКИЕ ПРАВИЛА (НИКОГДА НЕ НАРУШАТЬ!)

### ❌ ЗАПРЕЩЕНО

1. **НЕ** используй `mode: "append"` для `portfolio.json` - всегда `mode: "rewrite"`
2. **НЕ** удаляй `portfolio.json` без создания backup
3. **НЕ** используй относительные пути - только абсолютные
4. **НЕ** коммить без проверки валидности JSON
5. **НЕ** работай с русским текстом без `encoding='utf-8'`

### ✅ ОБЯЗАТЕЛЬНО

1. **ВСЕГДА** создавай backup перед изменением `portfolio.json`
2. **ВСЕГДА** проверяй валидность JSON после изменений
3. **ВСЕГДА** используй абсолютные пути
4. **ВСЕГДА** делай коммит после успешных изменений
5. **ВСЕГДА** тестируй на разных устройствах перед deploy

## 📝 РАБОТА С PORTFOLIO.JSON

### Структура проекта
```json
{
  "id": "unique-project-id",
  "title": "Название проекта",
  "category": "residential|office|restaurant|other",
  "categoryName": "Жилые помещения|Офисы|Рестораны|Коммерческие",
  "area": "35 м²",
  "year": "2024",
  "style": "Стиль интерьера",
  "services": "Дизайн интерьера, 3D-визуализация",
  "description": "Краткое описание для карточки",
  "fullDescription": ["Абзац 1", "Абзац 2", "Абзац 3"],
  "features": ["Особенность 1", "Особенность 2"],
  "mainImage": "images/portfolio/project-folder/main.jpg",
  "gallery": [
    {
      "url": "images/portfolio/project-folder/photo1.jpg",
      "alt": "Описание изображения",
      "large": true
    }
  ]
}
```

### ⚠️ Важно про пути изображений

**В JSON указываем**:
```json
"mainImage": "images/portfolio/terrace-scandinavian/photo_1.jpg"
```

**Реально файлы лежат**:
```
C:\Users\pa8hka\Desktop\site\Портфолио\Терраса загородного дома в скандинавском стиле\photo_1.jpg
```

### Работа через Python

```python
import json

# Загрузка
with open(r'C:\Users\pa8hka\Desktop\site\data\portfolio.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# Добавление проекта
new_project = {
    "id": "new-project-id",
    "title": "Название",
    # ... остальные поля
}
data['projects'].append(new_project)

# Удаление проекта по ID
data['projects'] = [p for p in data['projects'] if p['id'] != 'project-to-delete']

# Сохранение (ВСЕГДА с ensure_ascii=False для кириллицы!)
with open(r'C:\Users\pa8hka\Desktop\site\data\portfolio.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

## 🚨 ТИПОВЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: Ошибка загрузки portfolio.json на сайте
**Симптомы**: "Ошибка загрузки проектов" на странице портфолио

**Решение**:
```cmd
# 1. Проверить валидность
python -m json.tool data/portfolio.json

# 2. Если ошибка - восстановить из Git
git restore data/portfolio.json

# 3. Или из backup
copy data\portfolio_backup.json data\portfolio.json
```

### Проблема 2: Файл portfolio.json задублировался
**Причина**: Использован режим `append`

**Решение**:
```cmd
git restore data/portfolio.json
```

### Проблема 3: Изображения не загружаются
**Проверки**:
1. Файлы в правильной папке? `Портфолио\[Название]\`
2. Пути в JSON правильные? `images/portfolio/project-id/photo.jpg`
3. Названия файлов совпадают? (регистр важен!)

### Проблема 4: Сайт не обновляется после push
**Причина**: Кэш браузера

**Решение**:
- Ctrl+F5 для жёсткой перезагрузки
- Или открыть в режиме инкогнито
- Подождать 2-3 минуты для деплоя
