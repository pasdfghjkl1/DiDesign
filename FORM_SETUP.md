4. ✅ Форма готова к работе

## 🔧 Что нужно сделать:

### Шаг 1: Получить Access Key от Web3Forms

1. Перейдите на сайт: **https://web3forms.com**
2. Нажмите кнопку **"Get Started - It's Free"**
3. Введите ваш email (куда будут приходить заявки)
4. Подтвердите email
5. Скопируйте ваш **Access Key** (выглядит примерно так: `a1b2c3d4-e5f6-7890-abcd-ef1234567890`)

### Шаг 2: Добавить Access Key в код

1. Откройте файл `form-handler.js`
2. Найдите строку:
   ```javascript
   accessKey: 'YOUR_ACCESS_KEY_HERE', // ⚠️ ЗАМЕНИТЕ НА ВАШ КЛЮЧ!
   ```
3. Замените `YOUR_ACCESS_KEY_HERE` на ваш Access Key:
   ```javascript
   accessKey: 'a1b2c3d4-e5f6-7890-abcd-ef1234567890',
   ```
4. Сохраните файл

## 📋 Как это работает:

1. **Пользователь заполняет форму** на главной странице (секция #contact)
2. **При отправке** данные отправляются на сервер Web3Forms
3. **Web3Forms** пересылает данные на ваш email
4. **Пользователь видит уведомление** об успешной отправке
5. **Форма очищается** автоматически

## 📧 Что будет приходить на email:

Каждое письмо будет содержать:
- **Имя** клиента
- **Телефон** клиента
- **Email** клиента
- **Сообщение** от клиента
- **Тема**: "Новая заявка с сайта DI Studio"

## ⚙️ Настройки (опционально):

### Изменить текст уведомлений:

В файле `form-handler.js` измените:
```javascript
const FORM_CONFIG = {
    accessKey: 'ваш_ключ',
    successMessage: 'Ваш текст успешной отправки',
    errorMessage: 'Ваш текст ошибки'
};
```

### Добавить автоответ:

В файле `form-handler.js` добавьте в `formData`:
```javascript
const formData = {
    name: '...',

    message: '...',
    subject: 'Новая заявка с сайта DI Studio',
```

## ⚠️ Возможные проблемы:

### Проблема: "Access Key не настроен"
**Решение**: Замените `YOUR_ACCESS_KEY_HERE` на реальный ключ

### Проблема: Письма не приходят
**Решение**: 
1. Проверьте папку "Спам" в почте
2. Проверьте правильность Access Key
3. Убедитесь, что email подтверждён на Web3Forms

### Проблема: Ошибка при отправке
**Решение**:
1. Откройте консоль браузера (F12)
2. Посмотрите на ошибки
3. Проверьте интернет-соединение
